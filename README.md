# EV Charging Station Performance Analysis

## Overview

This project demonstrates an end-to-end data analytics workflow using Microsoft Excel, Power Query and Oracle SQL. The objective is to analyze large-scale EV charging station operational data to identify charging utilization, waiting time, pricing, city performance and network performance.

---

## Project Objectives

- Import and validate more than 1.3 million records
- Perform SQL-based data cleaning
- Create reusable SQL views
- Analyze charging station utilization
- Analyze city and network performance
- Generate business insights and recommendations

---

## Dataset Summary

| Metric | Value |
|--------|------:|
| Total Records | 1,317,750 |
| Charging Stations | 150 |
| Cities | 15 |
